# 阅读器状态说明

## 各层负责什么

- `AppState`：打开、关闭阅读器，保存最后阅读的章节；不管理阅读页里的图片位置。
- `ReaderState`：当前图片、可滚动的图片列表、后台预取和工具栏。所有修改都在主线程执行。
- `ComicReader`：渲染图片，把可见图片变化传给 `ReaderState`；横竖阅读模式仍由 `@AppStorage` 保存。
- `ReaderComicImage`：保存自己的图片尺寸和可见状态，离屏后保留宽高比、释放图片视图。
- `ReaderImagePrefetcher`：管理预取队列、并发数和请求取消，不修改阅读位置。
- `ContentButton`：自己保存目录弹窗是否打开，选择章节时调用 `jumpToChapter`。

## 哪些状态需要保存

| 状态 | 含义 |
| --- | --- |
| `currentImage` | 当前读到的图片，是阅读位置的唯一来源；空章节时为 `nil`。 |
| `imageList` | 当前这轮阅读已经展开的图片，接近末尾时追加后续章节。它保存 URL 和序号，不保存图片位图。 |
| `startChapterIndex` | 此轮阅读从哪章开始；没有图片时用来显示所选章节。 |
| `readingID` | 手动跳章时更新，用于重建滚动视图、拒绝旧滚动回调。 |
| `imagePixelWidth` | 当前视口宽度乘以屏幕缩放比例，决定预取图片的像素宽度；不触发视图更新。 |
| `imagePrefetcher` | 当前阅读器的预取器；不触发视图更新。 |
| `showToolbar` / `hideTask` | 工具栏可见状态和自动隐藏计时任务。 |

这些状态只有 `ReaderState` 能修改。视图通过事件方法更新它们。

## 哪些状态不再单独保存

- 当前章节：`currentImage.chapterIndex`；没有图片时使用 `startChapterIndex`。
- 当前页码：`currentImage.indexInChapter + 1`。
- 下一章：从 `imageList` 最后一张图片的章节推导，跳过没有图片的章节。
- `imageIndex`、`nextChapterIndex`、与图片列表等长的 `imageLoaded` 数组已删除。
- `preloaded` 已删除。阅读器立即显示图片或占位图，后台预取不控制页面的显示与隐藏。
- 全局 `imageSizes` 和 `requestedImageURLs` 已删除。每个图片视图保存自己的尺寸，预取队列交给预取器管理。

## 只看这几个事件

1. **进入阅读器**：初始化所选章节和第一张图片，视图通过 `start(pixelWidth:)` 传入显示宽度，准备后续图片、显示工具栏。视口宽度变化时更新预取尺寸。
2. **滚动**：`visibleImagesChanged` 找出最靠前的可见图片，更新 `currentImage`，再追加章节和预取。
3. **手动跳章**：`jumpToChapter` 取消旧预取，替换图片列表，把 `currentImage` 指向第一张，更新 `readingID`，开始新章节的预取。
4. **切换横竖模式**：视图用 `currentImage` 恢复位置，不改变章节和页码状态。
5. **退出**：`close()` 取消预取和工具栏计时，通过 `onClose` 将当前章节交回 `AppState`。视图消失时也停止预取，清除预取宽度，防止迟到的滚动回调再次发起请求。

## 为什么还有少量检查

检查集中在输入边界：初始化时处理失效的历史位置，选章时检查章节范围，滚动时拒绝旧 `readingID` 和空的可见列表，图片处理时检查数据和尺寸。

内部不再反复检查图片索引：当前图片直接来自本轮列表，不通过一个独立、可失效的索引读取。图片预取不修改阅读状态；预取器通过请求对象身份区分同一 URL 的旧请求和新请求，避免已取消请求的回调移除新任务。

## 图片性能

- `ImageDownsampler` 使用 ImageIO 按显示像素宽度直接解码，处理照片旋转信息，保持长条漫画的宽高比，不放大小图。
- 显示与预取使用相同的处理器和独立缓存。阅读页内存缓存上限为 192 MiB，封面缓存上限为 128 MiB；这些是缓存配置，不是应用总内存的硬上限。
- 磁盘缓存只保存处理后的阅读图片，各像素宽度分别缓存。首次使用新宽度或从旧版缓存迁移时需要重新下载。
- 滚动时预取前方最多 6 张，预取并发最多 2 个。窗口移动时保留重叠请求，取消移出窗口的请求；可见图片的加载由各视图管理。
- 图片视图异步读取磁盘缓存、后台解码，离屏后取消加载并移除持有位图的子视图。
- 图片尺寸只更新对应图片视图，不再通过共享状态通知整个阅读器；已有内存缓存时直接使用其尺寸，减少占位布局变化。

## 验证

在项目根目录运行：

- `sh Tests/run-reader-state-tests.sh`：编译实际的状态和模型，使用预取器替身，覆盖跳章、旧滚动回调、短章节、空章节、预取窗口和关闭行为。
- `sh Tests/run-image-downsampler-tests.sh`：使用生成的 JPEG 检查缩小后的像素尺寸和位图存储量、EXIF 旋转、长条漫画、小图和无效数据。
- `sh Tests/run-search-index-tests.sh`：确认搜索索引相关行为没有回归。

这些测试不包含真机滚动帧率、实际网络请求调度或峰值内存测量，仍需在手机上用原先卡顿的图片验证。
